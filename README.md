# Контакты — рабочая доска

Офлайн-приложение для импорта заявок из Excel, работы на канбан-доске и планирования звонков. Данные остаются на компьютере пользователя.

## Что уже работает

- импорт XLSX с выбором листа, сопоставлением столбцов и предпросмотром;
- обновление повторной заявки по источнику + ID записи;
- обновление контакта и его текущей заявки по нормализованному телефону в рамках одного источника;
- отдельное хранение контактов и заявок;
- канбан с собственными этапами и drag-and-drop;
- карточка контакта, комментарии и история действий;
- звонки: просроченные, сегодня, завтра, 7 дней;
- общий список, поиск, фильтры, отчёты и экспорт в Excel;
- резервная копия и восстановление;
- пользовательские поля и настройки;
- отправка КП в MAX из карточки контакта, вход по QR-коду или по SMS в настройках;
- установка как приложение через Chrome/Edge и работа без интернета.

## Запуск

### Установка на новый компьютер

Это установка из исходников, она нужна для доработки программы. Для рабочего компьютера хватит готового архива, см. «Готовая сборка на Windows» ниже.

В командной строке от имени администратора:

```
winget install -e --id Git.Git --silent --accept-package-agreements --accept-source-agreements
winget install -e --id OpenJS.NodeJS.LTS --silent --accept-package-agreements --accept-source-agreements
winget install -e --id Python.Python.3.13 --silent --accept-package-agreements --accept-source-agreements
```

Закройте это окно и откройте новое, иначе установленные программы не появятся в `PATH`. Дальше без прав администратора:

```
git clone https://github.com/pinnnthreetriples/kontakt-board.git "%USERPROFILE%\kontakt-board"
cd /d "%USERPROFILE%\kontakt-board"
SETUP_WINDOWS.cmd
```

`SETUP_WINDOWS.cmd` ставит зависимости, собирает приложение и запускает его. Делается один раз, дальше программа открывается файлом `START_WINDOWS.cmd`.

Данные при переезде не копируются вместе с файлами, они лежат в браузере:

- контакты, заявки и звонки переносятся через «Настройки → Резервные копии»: на старом компьютере «Скачать копию», на новом «Восстановить»;
- в MAX нужно войти заново, по QR-коду или по SMS, файл сессии переносить не нужно и не стоит;
- журнал отправленных КП `%LOCALAPPDATA%\KontaktBoard\send_ledger.sqlite3` копируется отдельно, если важно, чтобы защита от повторной отправки помнила прошлые письма.

### Готовая сборка на Windows

Готовый архив лежит в [релизах](https://github.com/pinnnthreetriples/kontakt-board/releases/latest). Скачать, распаковать и запустить можно одной командой в `cmd`:

```
curl -L -o "%TEMP%\kontakt-board.zip" https://github.com/pinnnthreetriples/kontakt-board/releases/latest/download/kontakt-board-windows.zip && tar -xf "%TEMP%\kontakt-board.zip" -C "%USERPROFILE%" && "%USERPROFILE%\kontakt-board\START_WINDOWS.cmd"
```

Дальше программа открывается файлом `%USERPROFILE%\kontakt-board\START_WINDOWS.cmd`. Окно запуска оставьте открытым во время работы. Node.js, Git и исходники для этого не нужны.

Вместе с приложением в отдельном окне поднимается мост к MAX, без него отправка КП недоступна. Его тоже оставьте открытым. Для моста нужен Python 3.10 или новее, а при самом первом запуске — интернет: он один раз ставит свои библиотеки в `bridge/.venv`. Подробности в [bridge/README.md](bridge/README.md).

### Для разработки

```bash
npm ci
npm run dev
```

Откройте `http://localhost:4173`. В Chrome или Edge выберите «Установить приложение» в адресной строке. После первой загрузки программа открывается и работает без интернета.

Сборка для обычного локального сервера:

```bash
npm run build
npm run preview
```

## Важно про Excel

Телефон и ID записи должны быть текстом. Если Excel уже округлил длинный ID, программа не сможет восстановить потерянные цифры.

Ограничения импорта: файл до 15 МБ, распакованное содержимое до 120 МБ, суммарно до 20 000 строк, 50 листов и 250 столбцов на лист. Рабочий сценарий MVP проверен на 10 000 заявок. Перед изменяющим импортом программа автоматически начинает скачивание резервной копии.

Данные находятся только в профиле браузера на этом компьютере. Не очищайте данные сайта и регулярно сохраняйте резервную копию в разделе «Настройки → Резервная копия».

## Следующий этап для команды

При появлении нескольких пользователей локальное хранилище заменяется сервером: PostgreSQL, API, вход и роли. Модель уже разделяет контакты, заявки, этапы, звонки и историю, поэтому UI не придётся переделывать целиком.
