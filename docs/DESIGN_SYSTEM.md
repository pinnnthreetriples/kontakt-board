# Design System

Основа: Material 3-подход через Material UI. Все общие решения находятся в `src/shared/design-system`.

## Токены

- семантические цвета: brand, surface, text, border, danger, warning, success;
- шкала отступов: 4, 8, 12, 16, 24, 32;
- радиусы: 8, 12, 18 и pill;
- единая типографика Inter;
- семантические веса текста и размеры основных областей, полей, иконок и состояний;
- две тени: карточка и плавающая панель;
- единая длительность анимаций.

## Правила

- Никаких случайных цветов, ширин, высот, радиусов и весов текста в страницах и компонентах. Автоматический gate проверяет эти свойства.
- Красный используется только для ошибки и просрочки.
- На канбан-карточке показывается не более шести элементов.
- Опасные действия объясняются; удаление непустого этапа запрещено.
- Минимальная зона нажатия — 40×40 px.
- Поддерживается системное уменьшение анимаций.
